CSS Information :-

CSS (Cascading Style Sheets) is a style sheet language used to describe the presentation of a document written in HTML or XML. It controls the layout, colors, and fonts of web pages.

Core Components :-
CSS uses a system of selectors and properties to define the appearance of elements on a web page. Selectors: The elements or groups of elements that you want to style. Properties: The characteristics of the selected elements that you want to modify, such as color, font-size, or margin. Values: The specific settings for each property.


How CSS Works :-
CSS works by applying rules to specific HTML elements. Each rule consists of two main parts:
  1. Selector: This part specifies which HTML elements the rule applies to. For example, "p" selects all paragraph elements, while ".class-name" selects all elements with a specific class attribute.
  2. Declaration Block: This part contains one or more declarations enclosed in curly braces {}. Each declaration consists of a property and a value, separated by a colon. For example, "color: red;" sets the text color to red.

The "Cascading" Concept :-
The term "Cascading" refers to how the browser resolves conflicts when multiple rules apply to the same element. It follows a priority scheme based on:

  • Importance: Rules marked with !important override all other rules.
  • Specificity: More specific selectors (like an ID) override less specific ones (like a tag name).
  • Source Order: If two rules have the same importance and specificity, the one defined later in the code takes precedence.


Methods of Implementatione :-
There are three ways to apply CSS to a website:

  • External CSS: Styles are kept in a separate .css file and linked to multiple HTML pages. This is the best practice for consistency and performance.
  • Internal CSS: Styles are defined within a style tag in the head section of an HTML document. This is useful for single-page styles but can lead to maintenance issues.
  • Inline CSS: Styles are applied directly to a specific HTML element using the style attribute.
